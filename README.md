# 📝 TextUtils – Django Text Analysis Web Application

## 📌 About the Project

**TextUtils** is a web-based text analysis application built using **Python** and **Django**. It allows users to analyze and manipulate text through various processing features such as removing punctuation, converting text to uppercase, removing extra spaces, and counting characters.

This project demonstrates backend development concepts including efficient text processing, request handling, modular application design, and clean architecture using the Django framework.

---

## 🚀 Features

- ✂️ Remove Punctuation
- 🔠 Convert Text to Uppercase
- 🧹 Remove Extra Spaces
- 🔢 Count Characters
- ⚡ Fast Text Processing
- 📱 Simple and User-Friendly Interface
- 🏗️ Modular and Maintainable Django Architecture

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/textutils.git
```

### 2. Navigate to the Project Directory

```bash
cd textutils
```

### 3. Create a Virtual Environment

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

**Linux/macOS**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Development Server

```bash
python manage.py runserver
```

### 6. Open in Browser

```
http://127.0.0.1:8000/
```

## 💻 How It Works

1. Enter or paste text into the input box.
